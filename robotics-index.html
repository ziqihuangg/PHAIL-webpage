Robotics Index

Ranks count every fitted model, so a filtered view keeps the original numbers. Each model's best entry on each board is used.

Index method

What
One number per model, 0-100: how often it would beat the other ranked models. models from boards.
Why
No single board tests every model, and each board alone is noisy, so the boards are pooled.
How
Inside each board, count who beat whom - scores are never added across boards. Pool all these results into one strength per model, as Elo does for chess players, then turn the strengths into the 0-100 index.

Each point opens for details; the numbers there are for the default settings and are recomputed from the Ledger on every load.

  2. Never add scores across boardsA board only says who beat whom. on RoboDojo and on RoboChallenge are different scales.
    Details

    Intuition. Boards differ in tasks, robots, number of trials and in what a point is worth: a success rate, a progress score, an Elo rating. The top of one board can sit at the bottom of another. So a raw score is only read against the other scores on the same board - which model is above which, and by how much relative to the noise (next step).

    The Method switch's "Raw mean" does exactly what this step forbids - a weighted average of raw scores - so the difference can be seen.

  3. Small gaps count as tiesP(A beats B) = Φ(gap / noise), with noise from the board's trial count. A 1-point gap over real trials is only about .
    Details

    Intuition. A board runs each model a limited number of times, so every score carries sampling noise. A gap smaller than that noise is close to a coin flip, so it counts as a near-tie rather than a clean win; a gap several times the noise counts as a full win.

    noise of one score\(\displaystyle \mathrm{SE} = 100\,\sqrt{\frac{p\,(1-p)}{n}}\)
    \(p\) = score / 100, kept between and ; \(n\) = trials per model
    noise of a gap\(\displaystyle \sigma = \sqrt{\mathrm{SE}_A^{2} + \mathrm{SE}_B^{2}}\)
    win share\(\displaystyle \Pr(A \text{ beats } B) = \Phi\!\left(\frac{\text{score}_A - \text{score}_B}{\sigma}\right)\)
    B gets \(1 - \Pr(A \text{ beats } B)\)
    normal curve\(\displaystyle \Phi(0) = 0.50, \quad \Phi(1) \approx \cfgphione, \quad \Phi(2) \approx \cfgphitwo\)

    Reading an Elo rating (RoboArena)

    Intuition. RoboArena has no success rate. Evaluators run two anonymous policies on a task of their choice and say which did better; every vote is one match. Ratings are fitted so that the gap between two ratings predicts which policy is preferred, as in chess. Only gaps mean anything: the level (around ) is arbitrary, so there is no ceiling and no best score to compute a difficulty from - step 4 gives Elo boards a neutral .

    preferred\(\displaystyle \Pr(A \text{ preferred over } B) = \frac{1}{1 + 10^{-(R_A - R_B)/400}}\)
    rules of thumb\(\displaystyle R_A - R_B = 0 \;\Rightarrow\; 0.50, \qquad 100 \;\Rightarrow\; \cfgeloone, \qquad 400 \;\Rightarrow\; \cfgelofour \;\; (10 \text{ to } 1)\)
    link to step 6\(\displaystyle s = 10^{R/400}\)
    the same Bradley-Terry curve, with strength written on a base-10 scale

    RoboArena also publishes a standard deviation per policy - the uncertainty of its own fit - and the index uses it as SE in the formulas above.

  4. Harder boards count moreDifficulty = 1 − best score / 100: (best ) ≈ , RoboDojo Sim (best %) ≈ . One operator's boards share one weight.
    Details

    Intuition. A board whose best model already scores can no longer tell good models apart; one whose best scores % still has room. Two boards from the same operator measure much the same thing, so they share one vote. An operator-run table counts as much as a paper's table.

    difficulty\(\displaystyle d = 1 - \frac{\text{best score}}{100}\)
    kept between and 1; Elo boards have no ceiling, so \(d = \cfgdneutral\)
    family share\(\displaystyle f = \frac{1}{\text{number of boards from the same operator in view}}\)
    evidence\(\displaystyle e = \begin{cases} \cfgebench & \text{operator-run board} \\ \cfgepaper & \text{pooled paper tables} \end{cases}\)
    weight\(\displaystyle w = d \cdot f \cdot e, \qquad \text{share of the index} = \frac{w}{\sum_{\text{boards}} w}\)
  5. Big boards don't outvote small onesEach model receives a board's weight once, however many rivals share that board.
    Details

    Intuition. A board with many models produces far more pairs than a small one. If every pair counted the same, the biggest board would decide the ranking on its own.

    weight per pair\(\displaystyle \omega = \frac{w}{k - 1}\)
    on a board with \(k\) ranked models
    weight per model\(\displaystyle (k - 1) \cdot \frac{w}{k - 1} = w\)
    each model sits in \(k - 1\) pairs, so it receives the board's weight exactly once, whatever \(k\) is
  6. Fit the strengths (Bradley-Terry)Every model gets one number, its strength \(s\): the chance that A beats B is \(s_A / (s_A + s_B)\). All strengths are fitted to every weighted head-to-head result at once - the maths behind Elo and Chatbot Arena.
    Details

    Intuition. Think of Elo ratings in chess, or Chatbot Arena for language models. Each model gets one hidden number, its strength. When two models meet, the stronger one usually wins, and the bigger the gap the surer the win. We do not set the strengths by hand: we choose the ones that best explain all the comparisons from steps 3-5 at once. Comparisons chain - A beat B on one board, B beat C on another - so the fit can place A above C even if A and C never met. Models that sit on two or more boards are those links.

    model\(\displaystyle \Pr(i \text{ beats } j) = \frac{s_i}{s_i + s_j}, \qquad s_i > 0\)
    log scale\(\displaystyle \beta_i = \ln s_i: \qquad \Pr(i \text{ beats } j) = \frac{1}{1 + e^{-(\beta_i - \beta_j)}}\)
    the logistic curve Elo ratings use (step 3)
    data\(\displaystyle \omega_{ij} = \frac{w}{k - 1} \;\text{(steps 4-5)}, \qquad W_{ij} = \text{win share (step 3)}\)
    fit\(\displaystyle \max_{s} \; \sum_{\text{pairs}} \omega_{ij} \left[ W_{ij} \ln \frac{s_i}{s_i + s_j} + (1 - W_{ij}) \ln \frac{s_j}{s_i + s_j} \right]\)
    start\(\displaystyle s_i = 1 \quad \text{for every model}\)
    update\(\displaystyle s_i \;\leftarrow\; \frac{\tfrac{\pi}{2} + \sum_j \omega_{ij} W_{ij}}{\tfrac{\pi}{s_i + 1} + \sum_j \dfrac{\omega_{ij}}{s_i + s_j}}, \qquad \pi = \cfgprior\)
    top: the wins the model actually collected (weighted); bottom: how many wins each unit of strength earns against its current opponents. A model that wins more than its strength predicts moves up, one that wins less moves down. The \(\pi\) terms are a weak tie against a fixed reference of strength 1, so a model that lost - or won - every comparison still gets a finite strength (Hunter's MM algorithm, 2004)
    stop\(\displaystyle \max_i \big|\ln s_i^{\text{new}} - \ln s_i^{\text{old}}\big| < \cfgtol \quad \text{(at most } \cfgrounds \text{ rounds)}\)

    Worked example: one model's strength

  7. From strengths to the index0-100: the model's average chance of beating each other ranked model, one at a time, computed from the strengths. Not a success rate, and not the share of models it is ranked above.
    Details

    A "match" here means the mix of tasks these boards test, weighted as in step 4 - not one particular task. 50 is the middle of this field.

    Intuition. Strengths have no natural unit. To make them readable, pair the model with every other ranked model in turn, take its chance of winning each pair from the strengths, and average those chances.

    index\(\displaystyle \text{Index}_i = \frac{100}{N - 1} \sum_{j \neq i} \frac{s_i}{s_i + s_j}\)
    \(N\) = number of ranked models

    Why the page shows the index, not the strengths

      • Relative to this field: adding many weak models raises everyone's index. That is why RoboChallenge T30-v2 entries that ran few tasks are left out (step 1).
      • Not a success rate: an index of does not mean % of tasks done.
    • Error bars: drop one board at a timeEach whisker runs from the lowest to the highest index the model gets when the whole index is recomputed without one of the boards. It shows how much the ranking leans on any single board; it is not a confidence interval.
      Details

      Intuition. With a handful of boards, one board can move a model a lot. So the whole index - noise, weights, fit - is recomputed once per board with that board removed, and the spread is shown instead of hidden. Removing a board the model is not on can move it too: the other models' strengths change, and the index is relative to them.

      full index\(\displaystyle I_i = \text{index of model } i \text{ from all boards } \mathcal{B}\)
      one board removed\(\displaystyle I_i^{(-b)} = \text{index of } i \text{ when board } b \text{ is removed and everything is refitted}\)
      refits that count\(\displaystyle D_i = \{\, b \in \mathcal{B} : i \text{ is still ranked without } b \,\}\)
      a model on one board disappears when that board is removed, so that refit is skipped
      error bar\(\displaystyle \Big[\, \min\big(I_i,\ \min_{b \in D_i} I_i^{(-b)}\big),\ \max\big(I_i,\ \max_{b \in D_i} I_i^{(-b)}\big) \Big]\)
      the rank range is the same with ranks in place of index values
      • Drop-one range (whiskers, table column) and rank range are these two intervals.
      • Held-out accuracy (Boards and weights): fit without board X, take the pairs on X whose gap exceeds their noise, and count how often the refit orders them the same way. 50% is a coin flip.
      • Boards column: a model on one board rests entirely on that board. Board agreement (below) compares the order two boards give their shared models.

    Board agreement

    • In short: when two boards test the same models, do they put them in the same order? Kendall's τ scores that from +1 (same order) through 0 (no relation) to −1 (reversed), using only the models both boards share ( or more).
    • Red cells lean towards reversed; the details show which τ could be chance.
    Details: what τ means and how it is computed

    Intuition. Take the models two boards have both ranked and look at every pair of them. If both boards put a pair in the same order, the boards agree on that pair; if they put it in opposite orders, they disagree. τ is the share of agreeing pairs minus the share of disagreeing pairs. It uses only the order, never the raw scores - the same rule as the index - so a success rate can be compared with an Elo rating.

    pairs\(\displaystyle \binom{n}{2} = \frac{n(n - 1)}{2}\)
    \(n\) = models both boards ranked; C = pairs both boards put in the same order, D = pairs they put in opposite orders, \(T_A, T_B\) = pairs tied on only one of the two boards (pairs tied on both are skipped)
    Kendall's τ-b\(\displaystyle \tau_b = \frac{C - D}{\sqrt{(C + D + T_A)(C + D + T_B)}}\)
    with no ties\(\displaystyle \tau = \frac{C - D}{n(n - 1)/2}, \qquad \text{share of pairs in the same order} = \frac{1 + \tau}{2}\)
    • +1: identical order. 0: no relation - whether the boards agree on a pair is a coin flip. −1: exactly reversed.
    • τ = 0.5 means the boards order about 3 pairs in 4 the same way; τ = −0.5, about 3 in 4 the opposite way.
    • Few shared models make τ very uncertain: with models there are only pairs, and one flipped pair moves τ by . Even for two unrelated boards τ scatters by about \(\pm\sqrt{\tfrac{2(2n + 5)}{9n(n - 1)}}\) - the chance level below. A τ inside twice that could be luck.
    • Computed on each board's published values (each model's best entry), not on the index. Boards need or more shared models to get a τ.

    • Leave one board out, fit the index on the others, and check the left-out board's clearly separated pairs: how many can it judge, and how many does it order correctly?
    • Compared with the single other board that shares the most models with it. If pooling helps, the index judges more pairs at equal or better accuracy.
